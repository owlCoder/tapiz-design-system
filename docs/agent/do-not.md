# Do not do this

- Do not add app-specific text or domain logic to the design system.
- Do not use raw hex colors or one-off inline theme values.
- Do not create a second table/card/button implementation in the app.
- Do not import React Router, TanStack Query, i18n, API clients, or auth code here.
- Do not force all surfaces to use the brutal style; use it as an explicit variant.
- Do not remove existing exports without a migration plan.
